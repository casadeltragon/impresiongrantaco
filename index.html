Protocolo PD01 51 78; canal AE30/AE01. El estado Bluetooth conectado no asegura que el mecanismo imprima. Si ninguna prueba mueve papel, copia el diagnóstico para revisar respuestas y estado físico.

2. Calidad, velocidad y logo

Ajusta un parámetro a la vez. Una impresión que se aclara progresivamente puede deberse a poca batería o temperatura; aumentar demasiado la energía puede empeorarlo.

Logo no cargado. Puedes obtenerlo de Supabase o elegirlo desde esta tablet.

La configuración se guarda solo en este navegador. Para el logo oficial el servidor consulta configuracion.logo_base64, la misma clave que utiliza el punto de venta.

3. Servidor de impresión V9 (piloto supervisado)

La tablet convierte los tickets del POS a imagen para la PD01. Primero haz una prueba de ticket completo y revisa el resultado antes de activar la cola. No confirmamos automáticamente que el papel haya salido.

Piloto: la cola original usa permisos anónimos amplios; no la utilices en producción hasta reforzar RLS, autenticación y autorización de dispositivos.

Detenido
Precaución: no abras dos servidores activos para esta misma impresora. Si Bluetooth se desconecta, el servidor permanece activado pero pausa el envío hasta reconectar. Los trabajos interrumpidos quedan en revisión, sin reimpresión automática. Verifica físicamente antes de reencolarlo.
Pantalla sin bloqueo solicitado

El servidor solo pasa a DETENIDO al pulsar Detener. Si Chrome se oculta o Bluetooth se desconecta, queda EN PAUSA y se reanuda al recuperar la conexión y visibilidad. Android puede suspender o cerrar Chrome; para imprimir con la pantalla apagada de forma fiable se necesita una app Android de servicio permanente. La función de pantalla activa depende de Android/Chrome. Un envío Bluetooth completado NO confirma la impresión física.
